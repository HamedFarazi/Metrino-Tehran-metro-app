Landmark 3D Models Directory

This directory contains 3D models for major Tehran landmarks.

REQUIRED FILE:
- miladtower.glb (Missing - needs conversion)

TO ADD MILAD TOWER MODEL:
1. Source file: public/miladtower.skp
2. Convert SKP to GLB using:
   - Blender (recommended)
   - Online converter: https://anyconv.com/skp-to-glb-converter/
3. Place result here: miladtower.glb

Expected specifications:
- Format: GLB (binary glTF 2.0)
- Height: 435 meters (real scale)
- Orientation: North-facing, vertical (Z-up)
- Polygon count: 20K-100K triangles
- File size: < 5MB

The 3D system is ready and will automatically load the model when available.
